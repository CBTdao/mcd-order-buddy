# 演示提示词（可直接复制）

> 前置：已在你的 AI 客户端接入麦当劳 MCP（`mcd-mcp`）并装载本 Skill。

## 场景一：热量预算配餐

```text
我今天只有 600 大卡的预算，帮我在麦当劳配一个晚餐套餐，
优先蛋白质高一点的，配完直接用最便宜的方式帮我下单，到店自取。
```

```text
我在减脂期，帮我对比一下麦香鱼和板烧鸡腿堡的热量和蛋白质，
再各配一个 400 大卡以内的组合。
```

## 场景二：省钱下单链路

```text
把能领的麦当劳优惠券全都领了，然后看看我常用的地址附近哪家店能送，
用券后最便宜的方案点一个巨无霸中套餐 + 玻柠茶。
```

```text
帮我算一下，用我现有的券，板烧鸡腿堡套餐券后多少钱？比原价省多少？
```

## 场景三：活动 · 积分 · 商城

```text
麦当劳这个月有什么活动？有没有快截止的？
```

```text
我的积分还有多少？有没有快过期的？帮我挑几个积分够得着、值得换的东西。
```

```text
查一下现在的积分抽奖，消耗多少积分一次？我的积分够抽几次？
```

## 一句话全链路（演示压轴）

```text
我中午只有 40 块预算和 700 大卡的胃口，附近 1 公里内的麦当劳，
帮我领券、比价、配餐、下单一条龙，下单前给我看一眼最终方案。
```

## 取消 / 售后

```text
刚才那个订单帮我取消了。
```

```text
查一下我最近的麦当劳订单，上周五那个买了什么？
```
